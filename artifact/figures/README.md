# Paper figures of de-stijl-motivation-isca27: one script per figure

Every figure of the motivation study (reports/experiments/de-stijl-motivation-isca27.md; curve source
reports/experiments/knee-sweep.md) is regenerated by one script here, either from the existing data (reprocess)
or by first measuring what is missing (measure). The plotting code is the final figure code, moved into the repo
(`plot/`, from workspaces/figs-isca27 + workspaces/figs-h1h2) with path handling and figure selection as the only
changes.

```
artifact/figures/
  fig1.sh .. fig8.sh   one per paper figure (with its variants, below)
  all.sh               every figure in one pass + index.md / all-final.html (captions with the numbers) + numbers.json
  common.sh            options, path resolution, run count, re-export, plot call, manifest (sourced)
  stages/              measurement shared by several figures: h1-slo-fixed.sh, h2-slo.sh, knee-sweep.sh
  plot/                final.py (all figures, --figs selects), knee_curves.py, cause_agg.py, pool.py, style.py,
                       lstyle.py, STYLE.md, gen_index_final.py, evidence_dirs.py
```

## Quick start

```
artifact/figures/fig5.sh --out /tmp/figs                 # reprocess from the existing exports (default mode)
artifact/figures/fig5.sh --reexport --out /tmp/figs      # evidence -> exporters -> CSVs -> figure
artifact/figures/fig5.sh --measure --dry-run             # print the measurement plan, run nothing
artifact/figures/all.sh --out /tmp/figs                  # all figures + index.md
```

Requirements for reprocess: bash, python3 with matplotlib (tested: Python 3.10.12, matplotlib 3.5.1), the exports and
the raw evidence they point to (Figs 1, 4 read the run-1 loadgen steps; Fig 8 the Popcorn counters). Each run writes
`<out>/<fig>.manifest.txt` (code commit + diff hash of artifact/figures, inputs, sha256 of every output).
Plotting runs under `nice -n 19` (and `numactl --cpunodebind=1 --membind=1` when present; `ARTIFACT_PY` overrides).

## Options (every figN.sh and all.sh)

| Option | Meaning |
| --- | --- |
| `--reprocess` | default: plot from the existing exports; stops with the list of missing inputs if some are absent |
| `--reexport` | first re-run the exporters (experiments/vectordb/export.py, experiments/eval/export_h2n.py, experiments/eval/knee_pilot_export.py) over the evidence behind the exports into `<out>/derived`, then plot from those; read only on the evidence |
| `--measure` | run the stages the figure needs (each skips runs whose exports exist), then plot |
| `--redo` | with `--measure`: measure every requested run again (new evidence versions) |
| `--runs N` | runs 1..N (default 3); run k uses loadgen seed SEED_BASE + k (eval2-h1.conf / eval2-h2.conf, SEED_BASE 20261020) |
| `--data DIR` | eval2 derived root (DIR/h1/vdb/vdb/run<k>-chain, DIR/h2/vdb/h2n/run<k>); DIR/knee-sweep is used as knee root when present |
| `--knee DIR`, `--plan CSV` | knee-sweep export root and plan (Figs 1, 4) |
| `--evidence-map OLD=NEW` | evidence moved: rewrite the source_dir prefix stored in the exports (repeatable) |
| `--out DIR` | output dir (default `$PWD/artifact-figures-out`) |
| `--dry-run` | print every command (stages, exporters, plot) and run or write nothing |

Path defaults (environment overrides, common.sh): `DESTIJL_ROOT` = the first parent of the repo holding
workspaces/eval2-derived; `EVAL2_DERIVED` = $DESTIJL_ROOT/workspaces/eval2-derived; `KNEE_DERIVED` =
$DESTIJL_ROOT/workspaces/knee-sweep/derived; `KNEE_PLAN` = experiments/eval/knee-sweep-plan.csv; `EVIDENCE_ROOT` =
$DESTIJL_ROOT/recovery; `MEASURE_TREE` = $DESTIJL_ROOT/CXL_SWMC; chains `RUNS123_CHAIN`, `H2N_CHAIN`,
`KNEE_CHAIN_V1`, `KNEE_CHAIN_V2` (workspaces/runs123/, workspaces/knee-sweep-chain-v{1,2}.sh);
`ARTIFACT_LOG_DIR` = $DESTIJL_ROOT/workspaces/artifact-measure (stage logs).

Figure rules kept exactly as the final set (workspaces/figs-isca27/out-final/index.md): mean of runs, no whiskers;
every axis ends at its last labeled tick, plain numbers; latency panels linear y with the SLO at 80-90 % of the height,
raised only when all of a system's points lie above it; Figs 1/4 curve = run 1's SLO-search points (pool.py, 3 %
pooling, shape filter) below 0.9 x base and knee-sweep points (lifetime_ok = 1, aborted = 0, after_abort = 0) from
0.9 x base, drawn while achieved search/s still rises (stop at the first > 5 % fall-back), run-1 points at
>= 0.97 x the first sweep rate dropped, Megalon floor panels = run 1's lowest step + sweep points; vertical unmarked
segment where the next measured step collapsed above the y top (main sweep, else the addendum lifetime); Fig 4 x range
shared per row; Fig 8 at Popcorn's own confirm window (steps.csv at_result).

## Measurement stages (shared; each figure calls only the stages it needs, and a stage skips what exists)

| Stage | Produces | Used by | Per run / once | Time |
| --- | --- | --- | --- | --- |
| stages/h1-slo-fixed.sh | per run k: `run-chain-v1.sh --run k --h1-only` (runset-vdb.sh, eval2-h1.conf: SLO searches + fixed L1/L2 windows) -> evidence recovery/eval2-run<k>-h1-n2-v<V>, export EVAL2_DERIVED/h1/vdb/vdb/run<k>-chain | Figs 1, 2, 3 (+ knee plan) | per run | ~3.9-4.6 h |
| stages/h2-slo.sh | per run k: `h2n-chain-v4.sh --run k` (eval2-h2.conf: install, VM8 switch, N = 2/4/8 blocks, restore, export + combine) -> recovery/eval2-run<k>-h2-n<N>-v<V>, EVAL2_DERIVED/h2/vdb/h2n/run<k> | Figs 4-8 (+ knee plan) | per run | ~7-8.5 h |
| stages/knee-sweep.sh | `knee-sweep-chain-v1.sh` (H1 2-VM + H2 N = 2/4/8; fixed-rate factors of the plan) and `knee-sweep-chain-v2.sh` (addendum: Popcorn H2 u90 N = 4/8, 1.00-1.30 x) -> KNEE_DERIVED/<group>/knee-pilot.csv | Figs 1, 4 | once (seed of run 1) | ~7.6 h + ~35 min |

The H2 SLO searches feed Figs 4-8 and are measured once: `fig5.sh --measure` after `fig4.sh --measure` (or
`all.sh --measure`) finds the exports and skips the stage. Order for a measurement from scratch: h1-slo-fixed (2-VM
state) -> h2-slo (switches to VM8 and restores) -> regenerate the knee-sweep plan from those runs -> knee-sweep.
`all.sh --measure` runs the three stages in that order (~3 x 4.3 h + 3 x 7.8 h + 8.2 h, about 45 h for 3 runs).

Measurement is main-session work inside the approved experiment (VMs, guest sudo, CXL device via
config/cxl_region*.yaml): the chains refuse while workspaces/MEASUREMENT.lock exists, when the live tree is dirty, and
(run-chain-v1.sh) when the live HEAD differs from runs 1-3's (EVAL2_ALLOW_HEAD_CHANGE=1). Launch long stages detached
(`setsid nohup .../figN.sh --measure ... > log 2>&1 &`). Stage dry-runs (`--measure --dry-run`) only print; the chains'
own deeper dry-runs (`run-chain-v1.sh --dry-run`, `h2n-chain-v4.sh --dry-run`) are run by hand when wanted.

## Limits

- The run chains (workspaces/runs123/run-chain-v1.sh, h2n-chain-v4.sh, workspaces/knee-sweep-chain-v{1,2}.sh,
  workspaces/vmN/vmN-chain-v2.sh) live in the control workspace, not in this repo; the stages call them by path.
- The eval2 chains accept `--run 1..3`; `--runs N > 3` is printed in a dry-run but refused for a real run until their
  run check (and the confs' RUNS) is widened.
- Re-measuring an existing run k (`--redo`) needs fresh switch / restore evidence dirs (VMN_E, VMN_E_RESTORE; the
  stage passes the environment through) and, for H1, EVAL2_ALLOW_HEAD_CHANGE=1 when the live HEAD changed.
- The knee-sweep plan (experiments/eval/knee-sweep-plan.csv) and the H2N_FIXED rate tokens of knee-sweep-h1.conf /
  knee-sweep-h2.conf are built from runs 1-3 (workspaces/knee-sweep-design/cross_runs.py -> knee_sweep_plan.py). For
  other runs they are regenerated by hand (a methodology input); stages/knee-sweep.sh refuses a plan built from other
  runs unless KNEE_PLAN_ACCEPT=1, and needs KS_H1_PRETOUCH_DIR for a real run.
